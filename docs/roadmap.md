# Roadmap

Este documento descreve as próximas etapas para tornar o simulador mais imersivo e fiel à realidade.

## Melhorias Planejadas
- **Clima e ambiente dinâmicos** que afetem rotas, produção e logística.
- **Modelos de física e colisão aprimorados** para representar interações com maior precisão.
- **Personagens controlados por IA** com comportamentos adaptativos e tomada de decisão realista.
- **Economia e cadeia de suprimentos em tempo real**, impactando preços, disponibilidade e demanda.
- **Sistema de eventos narrativos** que reaja às escolhas do jogador para aumentar a imersão.

## Integrações Desejadas
- API meteorológica para dados climáticos reais.
- Integração com motores de simulação física externos.
- Suporte a dispositivos de realidade virtual/aumentada.
- Conectores com plataformas de aprendizado online para métricas de desempenho.
