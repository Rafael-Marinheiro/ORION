# Roadmap

Este documento descreve as próximas etapas para evoluir o simulador como
ferramenta de aprimoramento das habilidades de administração e tomada de
decisão.

## Melhorias Planejadas
- **Simulação de mercado e concorrência** com agentes competidores e
  indicadores econômicos dinâmicos.
- **Módulo de planejamento estratégico** permitindo definição de objetivos,
  alocação de recursos e análise de cenários.
- **Relatórios financeiros detalhados** (DRE, balanço, fluxo de caixa) com
  análise de KPIs e alertas automáticos.
- **Eventos de risco e regulamentação** que exijam decisões rápidas sobre
  mitigação e compliance.
- **Gestão de pessoas e produtividade** incluindo contratação, treinamento e
  impacto no desempenho.

## Integrações Desejadas
- APIs de dados econômicos e financeiros para alimentar o mercado virtual.
- Conectores com ERPs/BI para importar ou exportar dados de desempenho.
- Integração com plataformas de e-learning para acompanhar evolução dos
  participantes.
- Suporte a dashboards externos para visualização avançada.
